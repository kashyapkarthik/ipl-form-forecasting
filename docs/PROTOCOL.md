# Analysis protocol

Committed before fitting or inspecting model performance on 2025–2026. Data coverage and counts were inspected during ingestion. This is a local analysis freeze, not a registered external study.

1. Brown-inspired experiment: calendar half of each season; beta-binomial prior fitted on early player counts only. Compare pooled probability, raw player probability and beta-binomial posterior mean. New late-half players receive population forecasts. Present all late-half observations and the subset with at least 11 opportunities in both halves. Report log loss, Brier score, equal-player squared error and arcsine noise-corrected squared error as a connection to Brown. The estimators themselves are beta-binomial, not Brown's full estimator suite.
2. Sequential cross-season experiment: every eligible batter has a forecast fixed before the match date. Annual population prior is fitted using player-season counts in the preceding three seasons. Same prior for all history methods. Compare all-history, current-season-only, rolling-ball and exponential-ball/day discounted counts. No population fitting on current-season outcomes. Use 2024 delivery-weighted log loss to choose one member of each recency family and the overall history method. Reserve 2025 and 2026 performance for evaluation. Earlier test outcomes can legitimately enter later predictions under the fixed update rule; no test-based parameter selection.
3. Preseason experiment: use the same candidates, but freeze each player's forecast before the entire target season. Select separately using 2024. Evaluate on 2025–2026. Zero-history batters receive a population prior, and future availability is not used to construct features. Report scores conditional on actual batting opportunities, not unconditional squad-selection predictions.
4. Context experiment: train a regularised logistic model on the preceding five seasons with historical pre-date expanding estimates, venue IDs, opposition, nominal phase, innings, observed batting-entry order, score/wickets before delivery, and season trend. Compare adding the pre-date selected-history minus expanding logit difference. Fit encoders/scalers only on past years. Predict each delivery given its pre-delivery context, a different information set from the pre-innings main model. This is an incremental predictive check, not a causal effect estimate. Report selected-history loss differences by venue/opposition/phase and exclude nonstandard innings as a sensitivity check.
5. Metrics: delivery-weighted log loss and Brier score; player-macro summaries; reliability curves; paired bootstrap of dates within each test season for loss differences. These conditional intervals do not include retraining uncertainty, inter-season regime uncertainty or every dependence across time. No independent-ball confidence intervals for model superiority.
6. Prospective watchlists: apply the preseason method selected on 2024, refit population parameters through 2026, and forecast at assumed 28 March 2027. Show all active 2026 batters; require 120 latest-season and 300 pre-latest-season opportunities for improver/rebound lists. Compare forecast with pre-2026 shrunk career baseline. Label candidates, not statistically proven improvers. Use within-player season-stratified innings-block resampling for uncertainty around forecasts and forecast-minus-baseline, refitting population parameters with shared Bayesian-bootstrap player weights. Selection/model/regime uncertainty remains unmodelled. Rebound candidates have latest observed rate below baseline and forecast above latest rate. If there is no convincing positive improvement, say so.
7. Visual case studies are descriptive illustrations selected after analysis and are not additional held-out tests. Historical model choice does not establish permanent ability change. Source data are a current retrospective vintage.

Configuration, thresholds, seeds and grids live in `config/protocol.json`. Later implementation fixes must be recorded without retuning the protocol to test outcomes.
